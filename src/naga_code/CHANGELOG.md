# Naga Code release notes

## 0.1.0
- Local-first terminal coding agent on Ollama, llama.cpp or vLLM; no cloud model or account needed.
- Tiger logo, arrow-key menus for approvals, yes/no questions and `/model`.
- Slash commands modelled on popular coding agents: `/rewind`, `/btw`, `/recap`, `/branch`, `/fork`,
  `/background`, `/loop`, `/goal`, `/effort`, `/fast`, `/advisor`, `/batch`, `/ultraplan`, `/ultrareview`,
  `/simplify`, `/verify`, `/security-review`, `/plugin`, `/import`, `/schedule`, `/theme`, `/vim` and more.
- Commands that need a cloud account are listed under "Not available" in `/help`.
- Recognizes Qwen-style XML tool calls written as plain text.
- The project folder search no longer climbs into your home directory.
